# 计划调整与 Auto-regulation

## 计划来源

- 训记官方计划是基线，只读。
- 读取：`sync-plan` → `plan --date`；字段来自 `plan_open_api_v1` 的 `res.days`。
- coach 可以建议改动作、组数、重量、RPE、休息，但不能通过 API 改官方计划。
- 训练记录写回只写实际完成的训练；不改计划本身。

## 决策输入

- 今日 readiness（睡眠、HRV、RHR、压力、SpO₂、昨日负荷）。
- 训记今日计划（动作、目标组次）。
- 昨日实际完成度、部位和训练量。
- 今日步数/活动、日间心率。
- 近期同动作表现和 RPE。
- 疼痛/红旗/异常心搏。

## 调整矩阵

### 绿（readiness ≥ 70，数据覆盖足够）

- 按计划推进。
- 渐进超负荷只选一个：
  - 同重量多做 1–2 次；或
  - 加 1 组；或
  - 小幅加重 2.5–5%（复合动作）或 1–2.5 kg（孤立动作）。
- 不同时加组、加重、缩休息。

### 黄（40–69，或低置信度但原始分为绿）

- 减少 1–2 个正式组，**或** RPE 上限降到 7–8；不同时做。
- 优先保留复合动作；先减孤立动作和递减组。
- 有氧改低强度 10–20 分钟；不做补偿性高强度。
- 若昨日同部位训练量大且今天仍酸痛，优先换部位或降阶。

### 红（< 40，或红旗）

- 主动恢复/休息；不做高疲劳复合动作。
- 有红旗症状：停止训练建议，建议专业评估。
- 不安排惩罚性有氧或极端节食。

## 训练量地标

- 每个肌群先从能稳定完成的较低周组数开始（例如 8–12 组/周），连续 2–4 周观察表现、恢复和围度/体重趋势。
- 接近最低有效量（MEV）时优先加组；接近最大可恢复量（MRV）时优先维持或减量。
- 不把 RP 的 MEV/MRV 当成精确处方；它是范围，需要个人数据校准。
- 连续表现下降、RPE 升高、睡眠/压力恶化时，先减量 1–2 个变量，而不是加练。

## 渐进超负荷

- 双进阶：先在目标次数区间内增加次数，再加重并回到区间下沿。
- 记录同动作的重量、次数、RPE、组数和休息；只和同动作/相近变式比较。
- 混合单位（kg/lb）不合并计算；自重动作需要体重或明确 `selfWeight`。
- 一次训练只改一个主要变量；连续 2–3 次成功后再进阶。

## 动作替代

- 优先同模式、同目标肌群、可控稳定的动作。
- 器械占用/居家条件：杠铃卧推 → 哑铃卧推/器械推胸/俯卧撑；杠铃划船 → 哑铃划船/坐姿划船；深蹲 → 腿举/保加利亚分腿蹲/高脚杯深蹲。
- 疼痛：先降负荷/改幅度/换变式；持续恶化、影响日常功能或神经症状 → 转介。
- 不用“泵感”或“酸痛”作为长期效果证据。

## 输出格式

```text
**今天：黄，按计划但降一档**
- 昨日胸部 12 组、训练量 4,200 kg；今天 HRV 52 ms（基线 61），RHR +6 bpm。
- 卧推：4 组 → 3 组，重量维持 70 kg，RPE 上限 8。
- 飞鸟：3 组 → 2 组；下压维持；不做递减组。
- 有氧：15 分钟快走，不做间歇。
你今晚还是 18:30 练吗？
```

## 写回

- 只写实际完成的训练记录；更新旧记录保留 `localid`、`start`、`end`、未完成组和 note 元数据。
- 先 `preview-train`，再 `clarify` 确认，最后 `confirm-train`。
- 结果未知先核对服务端记录，不自动重试。
