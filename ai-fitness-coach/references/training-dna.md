# 训练 DNA 与长期训练资产

训练 DNA 不是一次对话里“猜出来”的标签，而是随数据更新的假设系统。本 skill 的实现以 `coach.sqlite` 的归一化训练、readiness 和体重记录为输入，输出结构化 DNA 与变更差异。

## 什么时候读取

- 用户说“建立/更新训练 DNA”“为什么平台了”“下一周期怎么练”。
- 周报后需要把趋势转成长期决策。
- 训记数据至少积累 2–4 周，准备做周期调整。

## 输入

- `trains`/`movements`/`sets`：训练频率、动作、组次、重量、RPE、完成率、部位。
- `readiness`：每日分层和分项。
- `weights`：体重趋势（有则用，没有不补）。
- `decisions`：过去的调整与验证条件。

## 八类 DNA

1. **频率**：每周训练次数、训练日分布、连续性。
2. **训练量**：总组数、估算训练量、周均值、变化趋势。
3. **部位分布**：胸/背/肩/腿/二头/三头/核心/小腿的组数或训练量占比。
4. **主要动作反应**：同动作的负重、次数、训练量和 RPE 趋势；只比较同动作或相近变式。
5. **有氧反应**：低强度/节奏/间歇的时长、距离、心率、完成率；与阻力训练分开统计。
6. **恢复**：readiness 均值、低分天数、训练负荷与恢复的关系。
7. **依从性**：完成组率、被跳过的动作/部位、最短有效训练的执行情况。
8. **风险边界**：疼痛、异常心搏、红旗、需要降阶的动作；只做提示，不做诊断。

## 置信度

- `insufficient`：< 2 周或数据质量 < 0.4；只当观察。
- `low`：< 4 周或数据质量 < 0.6。
- `medium`：< 8 周或数据质量 < 0.8。
- `high`：≥ 8 周且数据质量 ≥ 0.8。
- 单次反馈不改 DNA；至少 2–3 个可比窗口且无替代解释，才提高置信度。
- 缺失日期、混合单位、未完成组过多时降低置信度，不制造趋势。

## 输出

运行：

```bash
python3 -m coach dna --weeks 8
```

返回 JSON：

- `window`：日期范围和周数。
- `confidence`：置信度。
- `metrics`：sessions、training_days、sets、completed_sets、volume_kg、adherence。
- `dimensions`：八类维度的状态、数值和证据。
- `evidence_ledger`：事实列表。
- `version_diff`：与上一版的 sessions/volume/confidence 差异。
- `limitations`：数据边界。

DNA 版本写入 `dna_versions`；人类可读的调整理由用 `python3 -m coach decision` 写入 `DECISIONS.md`。

## 长期资产

本 skill 不强制生成一堆文件；默认维护：

| 位置 | 作用 |
| --- | --- |
| `profile.json` | 目标、体重、训练时间、器械、伤病、饮食限制 |
| `coach.sqlite` | 训练/饮食/readiness/DNA/决策/写回记录 |
| `DECISIONS.md` | 每次调整的证据、理由、回退条件和下一次验证 |
| `dna_versions` | DNA 版本和差异 |

需要时再生成 Markdown 摘要；不把同一份内容重复写成多个文件。

## 决策日志格式

```text
日期：2026-11-04
类型：weekly_review
证据：训练 4 次，胸部 12 组，背部 8 组；readiness 均值 62；蛋白执行率 70%。
判断：胸部容量足够，背部低于最低有效量；恢复尚可。
行动：下周背部加 2 组划船，胸部维持；不改变训练日。
回退：如果背部出现持续酸痛或 readiness < 40，回到本周容量。
下一次验证：2026-11-11 看背部组数和划船表现。
```

## 禁止

- 用一次训练或一次状态定义“你的训练 DNA”。
- 把不同器械/不同动作的重量直接比较。
- 把 kg/lb 混算。
- 用 DNA 替代医学诊断或安全筛查。
- 为了生成完整 DNA 而填补缺失数据。
